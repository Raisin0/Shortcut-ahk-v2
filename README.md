AutoHotkey Shortcuts

A collection of useful Windows shortcuts made with AutoHotkey v2 to make everyday tasks faster and easier.

Shortcuts

Shortcut| Action
"Ctrl + Alt + D"| Create a new folder in the current File Explorer directory
"Ctrl + Alt + F"| Launch Firefox
"Ctrl + Alt + A"| Toggle maximize / restore
"Ctrl + Alt + Q"| Minimize the active window
"Ctrl + Alt + W"| Close the active window
"Ctrl + Alt + C"| Exit fullscreen (if supported), resize the active window to 500×600, and center it on the screen

Requirements

- AutoHotkey V2

Usage

1. Install AutoHotkey v2.
2. Download or clone this repository.
3. Run the ".ahk" script.
4. Use the shortcuts whenever you need them.

Note: Fullscreen behavior depends on the application. Some exclusive fullscreen games may not support automatic resizing.
